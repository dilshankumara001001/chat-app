 💬 Real-Time Group Chat App

A full-featured real-time group chat application built with **Node.js**, **Express**, and **Socket.IO**. 
This app allows multiple users to join a single chat room, send messages instantly, and see who's online — all in real time.

## ✨ Features

- 🔥 **Real-Time Messaging** – Powered by Socket.IO for instant bi-directional communication.
- 👥 **Online User List** – See who's currently online in the chat room.
- 🎨 **Clean UI** – Modern dark theme with a responsive layout.
- 🟢 **Join/Leave Notifications** – Get notified when a user joins or leaves.
- 💬 **Self/Other Message Differentiation** – Your messages appear on the right, others on the left.
- ⚡ **Single File Frontend** – All HTML, CSS, and JS are served from one file (no frontend build tools needed).
